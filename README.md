# AI Powered Expense Tracker

An intelligent full-stack expense management application that helps users track spending, manage budgets, and gain AI-driven financial insights.

## Live Demo
🌐 https://ai-powered-expense-tracker-ten.vercel.app/

## Features

- User Authentication (Register/Login with JWT)
- Add, Edit, Delete Expenses
- Category-wise Expense Tracking
- Budget Management
- Interactive Analytics Dashboard
- Expense Trends Visualization
- AI-Based Financial Insights
- Responsive Modern UI

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS3

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication

### Database
- MySQL
